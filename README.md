# منصة تذاكر الأطفال (تذكرة الحظ)

الأدمين ينشئ دفعات تذاكر فيها رابحة وغير رابحة، والطفل يدخل رمز تذكرته (أو يمسح QR) فيظهر له **"ألف مبروك!"** أو **"حظ أوفر"**. الرابح يُدخل جوال ولي الأمر، فتصله رسالة واتساب عبر Twilio.

- PHP 8.1+ و MySQL، بدون Composer وبدون أي مكتبات تحتاج تثبيت.
- يعمل على استضافة Hostinger المشتركة مباشرة.

---

## التشغيل المحلي على جهازك

### الطريقة 1: Docker (الأسهل، أمر واحد)

1. ثبّت [Docker Desktop](https://www.docker.com/products/docker-desktop/) و [Git](https://git-scm.com/downloads).
2. نزّل المشروع وشغّله:

```bash
git clone https://github.com/<حسابك>/kids-tickets.git
cd kids-tickets
docker compose up -d
```

3. افتح `http://localhost:8080/install/` وأدخل:
   - Host: `db` · Port: `3306` · اسم القاعدة: `kids_tickets` · المستخدم: `kt` · كلمة المرور: `ktpass`
   - رابط الموقع: `http://localhost:8080`
4. الموقع: `http://localhost:8080` · لوحة التحكم: `http://localhost:8080/admin/` · phpMyAdmin: `http://localhost:8081`
5. للإيقاف: `docker compose down`

### الطريقة 2: XAMPP (ويندوز بدون Docker)

1. ثبّت [XAMPP](https://www.apachefriends.org/) بإصدار PHP 8.2 أو أحدث، وشغّل Apache و MySQL من لوحة XAMPP.
2. انسخ المشروع إلى `C:\xampp\htdocs\kids-tickets` (أو `git clone` داخل `htdocs`).
3. افتح `http://localhost/phpmyadmin` وأنشئ قاعدة باسم `kids_tickets` (Collation: `utf8mb4_unicode_ci`).
4. افتح `http://localhost/kids-tickets/install/` وأدخل: Host `localhost` · المستخدم `root` · كلمة المرور فارغة.

### سير العمل اليومي

```bash
git pull                 # جلب آخر التحديثات
# عدّل الملفات وجرّب على localhost
git add . && git commit -m "وصف التعديل"
git push                 # رفع التعديلات إلى GitHub
```

ملف `config.php` لا يُرفع إلى GitHub أبداً (موجود في `.gitignore`) لأنه يحتوي كلمات المرور ومفاتيح Twilio.

## الرفع على Hostinger (10 دقائق)

1. **قاعدة البيانات:** hPanel ← Databases ← MySQL Databases ← أنشئ قاعدة ومستخدماً، واحفظ: اسم القاعدة، المستخدم، كلمة المرور.
2. **PHP:** hPanel ← Advanced ← PHP Configuration ← اختر 8.2 أو أحدث.
3. **رفع الملفات:** hPanel ← Files ← File Manager ← افتح `public_html` للدومين المطلوب ← ارفع `kids-tickets.zip` ← Extract. انقل محتويات المجلد إلى `public_html` مباشرة (أو اتركه في مجلد فرعي).
4. **التثبيت:** افتح `https://دومينك/install/` وأدخل بيانات القاعدة وحساب المالك ← تثبيت.
5. **مهم جداً:** احذف مجلد `install` من File Manager بعد التثبيت.
6. **SSL:** hPanel ← Security ← SSL ← فعّل الشهادة المجانية، ثم افتح ملف `.htaccess` واحذف علامة `#` من سطري إجبار HTTPS.
7. ادخل `https://دومينك/admin/` وأنشئ أول دفعة.

> ⚠️ لا ترفع المشروع على دومين عليه موقع شغّال (مثل pfsc-sa.com) إلا بعد أخذ نسخة احتياطية، لأنه سيستبدل الصفحة الرئيسية. الأفضل دومين خاص أو نطاق فرعي مثل `tickets.domain.com` (hPanel ← Domains ← Subdomains).

## إعداد Twilio وواتساب

الموقع يعمل بدون Twilio (يُسجَّل الرابح بدون رمز تحقق وبدون رسائل). لتفعيلها:

1. أنشئ حساباً في twilio.com وانسخ **Account SID** و**Auth Token**.
2. **رمز التحقق OTP:** Verify ← Services ← Create ← انسخ **Service SID** (يبدأ بـ VA).
3. **واتساب للتجربة:** Messaging ← Try it out ← WhatsApp Sandbox. الرقم المرسل `+14155238886`، وكل جوال يريد استقبال رسائل التجربة يرسل كلمة join الظاهرة هناك.
4. **واتساب للإنتاج:** اربط حساب Meta Business موثّق ورقماً مخصصاً عبر Twilio ← WhatsApp Senders. ثم أنشئ قوالب في Content Template Builder (الفوز، التسليم) وانتظر موافقة Meta، وضع رقم كل قالب (HX…) في لوحة التحكم ← الإعدادات.
5. افتح ملف `config.php` على السيرفر وعبّئ قسم `twilio`:

```php
'twilio' => [
    'account_sid'        => 'ACxxxxxxxx',
    'auth_token'         => 'xxxxxxxx',
    'verify_service_sid' => 'VAxxxxxxxx',
    'otp_channel'        => 'sms',          // أو whatsapp
    'whatsapp_from'      => '+14155238886', // رقم واتساب المرسل
    'sms_from'           => '',             // اختياري: رقم SMS احتياطي
],
```

6. لوحة التحكم ← الإعدادات ← "إرسال رسالة تجريبية" للتأكد.

## بوت واتساب 🤖

الطفل أو ولي الأمر يرسل رمز التذكرة على واتساب، والبوت يرد فوراً:

```
👤  98XH-2EKX-TX
🤖  🎉 ألف مبروك! ربحت: دراجة هوائية — رقم المطالبة: 98XH-2EKX-TX
    أرسل اسم الطفل الآن لإكمال تسجيل الجائزة.
👤  سارة
🤖  تم تسجيل جائزة سارة ✅ سنتواصل معكم على هذا الرقم لترتيب الاستلام.
```

- رقم الواتساب المرسِل يُعتمد كرقم ولي الأمر مباشرة، فلا حاجة لرمز OTP.
- نفس الحماية: كل تذكرة مرة واحدة، 5 محاولات خاطئة في الساعة لكل رقم، وحد للرسائل المتكررة.
- كل طلب يُتحقق أنه من Twilio فعلاً (توقيع `X-Twilio-Signature`)، والطلبات المزيفة تُرفض.
- الرسائل الواردة والصادرة تظهر في لوحة التحكم ← سجل الرسائل، والرابحون عبر واتساب عليهم شارة "واتساب".
- صورة الجائزة تُرسل مع رسالة الفوز (يتطلب أن يكون الموقع على https).

**التفعيل:**
1. أكمل إعداد Twilio في `config.php` (القسم السابق).
2. Twilio Console ← Messaging ← WhatsApp senders (أو Sandbox settings للتجربة) ← في خانة **When a message comes in** ضع:
   `https://دومينك/api/whatsapp.php` بطريقة `HTTP POST`.
3. لوحة التحكم ← الإعدادات ← بوت واتساب ← فعّل واحفظ. من نفس المكان تعدّل كل نصوص البوت.

بعد التفعيل يظهر زر "أرسل الرمز على واتساب" في الصفحة الرئيسية، ورقم الواتساب على التذاكر المطبوعة.

**تجربة البوت على جهازك (localhost):** Twilio لا يصل لجهازك مباشرة، فاستخدم [ngrok](https://ngrok.com/download):

```bash
ngrok http 8080
```

انسخ الرابط الذي يعطيك إياه (مثل `https://abc123.ngrok-free.app`) وضع في Twilio: `https://abc123.ngrok-free.app/api/whatsapp.php`.

## طريقة الاستخدام

| المهمة | من أين |
| --- | --- |
| إنشاء تذاكر | دفعات التذاكر ← دفعة جديدة: العدد + الجوائز وعددها + صورها |
| طباعة التذاكر | صفحة الدفعة ← طباعة (400 تذكرة لكل ملف، كل واحدة برمز + QR) أو CSV للمطبعة |
| إيقاف حملة فوراً | صفحة الدفعة ← إيقاف مؤقت |
| معرفة حالة تذكرة / إلغاء تذكرة ضائعة | البحث عن تذكرة |
| إضافة تذكرة واحدة (رابحة أو لا) | البحث عن تذكرة ← إضافة تذكرة يدوياً |
| تسليم الجوائز | الرابحون ← إجراءات ← تم التسليم (يرسل واتساب لولي الأمر) |
| تغيير نصوص رسائل واتساب واسم الموقع | الإعدادات |
| إضافة موظف | المشرفون (للمالك فقط) |

## الحماية المدمجة

- رموز من 10 حروف وأرقام (أكثر من 800 تريليون احتمال) بدون الأحرف المتشابهة.
- 5 محاولات خاطئة في الساعة لكل جهاز، ثم حظر مؤقت.
- كل تذكرة تُستخدم مرة واحدة، مع قفل في قاعدة البيانات يمنع استخدامها مرتين في نفس اللحظة.
- أماكن التذاكر الرابحة موزّعة بخلط آمن تشفيرياً، ولا تظهر في ملفات الطباعة، فالمطبعة لا تعرف الرابحة.
- النتيجة تُحسم في السيرفر فقط.
- حماية CSRF، كلمات مرور مشفّرة، حد لمحاولات دخول الأدمين، سجل عمليات، وخروج تلقائي بعد ساعتين خمول.
- مجلد الصور المرفوعة لا يشغّل أي سكربت.

## هيكل الملفات

```

api/redeem.php       كشف التذكرة
api/claim.php        تسجيل الرابح + OTP + واتساب
api/whatsapp.php     بوت واتساب (Webhook من Twilio)
admin/               لوحة التحكم
includes/            الاتصال بالقاعدة، منطق التذاكر، Twilio، ترقيات القاعدة
install/             معالج التثبيت + schema.sql (احذفه بعد التثبيت)
assets/              CSS و JS والأيقونات
uploads/             صور الجوائز
config.php           يُنشأ تلقائياً عند التثبيت (سري)
```
